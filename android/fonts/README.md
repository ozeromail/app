# Fonts

`app/src/main/res/font/` holds variable Inter (UI) and Literata (reading), cut down to Latin and Cyrillic with `pyftsubset`, keeping the `opsz` and `wght` axes. Both are under the SIL Open Font License 1.1; the texts are here.

- Inter: https://github.com/rsms/inter
- Literata: https://github.com/googlefonts/literata
